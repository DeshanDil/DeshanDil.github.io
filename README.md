# Deshan Dileepa — Portfolio

This is a static portfolio website for Deshan Dileepa Rathnamalala. It uses plain HTML, CSS and JavaScript, so it can be hosted free with GitHub Pages.

## Publish with GitHub Pages

1. Create a public repository named `DeshanDil.github.io`.
2. Upload `index.html`, `style.css` and `script.js` to the repository root.
3. Open the repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then click **Save**.
6. Visit `https://DeshanDil.github.io` after GitHub finishes publishing.

The profile image currently loads from the public GitHub avatar at `https://github.com/DeshanDil.png`. Replace that URL with a local image in an `assets` folder if you prefer to host the image in the repository.
